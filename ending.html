让每一个重大决策，先跑一遍

我们不替任何人做决定，只想在拍板之前，多帮着看一步路。

🧭给决策者

参数公开可改，通勤、投产、外迁拨一下看系统怎么响应，做方案前先跑一遍压力测试。

🏘️给普通人

你上班的东江湾、吃饭的江北CBD、每天走的那座桥，都在这张网里。一个项目晚两年、一条路堵了，会怎样影响你的工作和日子？只用公开数据跑一遍，讲人话。

同一台风洞 · 两种打开方式，都只看公开数据、都讲人话

这件事，在“数字中国”的蓝图里

城市决策的科学化，不是一个人、一个地方的心血来潮，而是国家早已指明的方向。

《中华人民共和国国民经济和社会发展第十四个五年规划和2035年远景目标纲要》提出：“加快构建数字技术辅助政府决策机制，提高基于高频大数据精准动态监测预测预警水平”，并要求“探索建设数字孪生城市”、“不断提高决策科学性”。
2023年中共中央、国务院印发的《数字中国建设整体布局规划》，按照“2522”整体框架布局，要求数字技术与经济、政治、社会等“五位一体”深度融合，“发展高效协同的数字政务”。

这台小小的产业风洞，正是把“数字技术辅助决策”落到一个城区的具体尝试——它不宏大，却是数字中国这座大厦里，一块看得见、摸得着、可核对的砖。

放眼世界，“先算后干”早已是通行做法

在区域和城市决策上先推演、后拍板，不是哪一国的专利。越是成熟的经济体，越舍得在这上面下功夫。

🇸🇬新加坡
Virtual Singapore

国土小、试错不起，建成全球首个国家级"数字孪生"，把整座城装进电脑，规划、建设、应急都先"试一遍"。

🇺🇸美国
REMI / IMPLAN

州和地方政府常用区域经济模型，加税、修路、建房、能源政策出台前，先算清带来多少就业、多少收入。

🇯🇵日本
Project PLATEAU

国土交通省主导，为约250个城市建成三维城市模型并开放数据，城市规划、防洪防灾都先在上面模拟。

🇰🇷韩国
数字孪生国土

把"数字孪生国土"写进国家空间政策，世宗、釜山先行试点，首尔用数字孪生实时模拟、调度交通。

🇬🇧英国
What Works Centre

成立"地方经济增长实证中心"，用证据回答"到底哪些政策真能拉动地方经济"，让决策少走弯路。

这些地方并非比我们更聪明，而是更早懂得——决策前多花一分“算”的功夫，决策后就能少交十分“试错”的学费。
我们做的，正是朝着这个方向，踏踏实实去努力。

我们为什么想做这件事

第一 · 数字背后是人

每个决策，都连着具体的人

一个早高峰赶班车的工人、一位为孩子学位操心的母亲、一个犹豫留不留的年轻人、一对守着小店的夫妻——城市的每个重大决定，最终都落在这样的人身上，走偏了，代价由他们承担。

第二 · 城市是个整体

牵一发，往往动全身

产业、人、空间早已咬合在一起，一个项目晚了、一条路堵了，会牵出一连串反应。只盯着眼前一个数字，很容易看不见整片森林，凭经验“拍脑袋”也越来越不够用。

第三 · 我们的态度

不炫技，只想帮上忙

一台模拟器替代不了一线的脚步、群众的智慧和决策者的担当。它能做的，只是在动手前多提供一种“先看一看”的可能，让选择更透明、可核对、能复盘。

正式版，还要接受更严格的检验

不是一步到位，而是沿“更全 → 更准 → 更稳 → 更实 → 更开 → 更远”一级级把功夫做扎实。

🌬️
更全

更多压力测试

极端天气、产业链断点、外部冲击、政策变化等多重压力同时发生的组合情景。

🎯
更准

更细找“命门”

把每个项目、每条关系、每个参数逐一扰动，精确找出“最不能出错”的位置。

🎲
更稳

上万次推演

让未来在不同条件下反复演化，给出更稳健的可能性分布，而非只给一个数字。

📡
更实

更真实数据

对接统计、交通、就业、教育等真实数据源，逐步减少假设成分，让结论更扎实。

🛠️
更开

可交互可核对

决策者自己改参数、提问题、现场推演，每一步都能回到公开资料核对。

🧭
更远

从看见到怎么走

不止指出哪里脆弱，更进一步和一线一起，推演具体行动怎么走、先后如何排。
