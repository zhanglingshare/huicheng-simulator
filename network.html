人话版26个节点，理论上最多能有325对关系，实际只连了37条可佐证主边，密度约11.4%。连得最多的是高新区，它是"现在的核心"；可你要问"哪根线最不能断"，用介数中心性算出来的第一名往往不是最大的那个节点——节点大不大不决定命门，它卡在什么位置，才决定。
边的数据血统（A/B/C/D）
A 实测：公开资料直接给出的关系（如明确的隔墙供应、管道连接）
B 推估：根据公开主体与产业逻辑可推断的供应/配套/载体关系
C 假设：合理推断但缺直接证据（如通勤关系，缺OD数据）
D 缺数：无公开数据支撑，纯模型假设（如跨城通勤量）
本页37条边中：A级 0 条，B级 0 条，C级 0 条，D级 0 条。导出的edges.csv含每条边的血统标注。
