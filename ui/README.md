# 界面系统（UI Layer）

这一层把原先“每页一套霓虹玻璃样式”的界面，收敛为一套接近 macOS / iOS / HarmonyOS 的视觉语法。
它只改表现层，不改模型、数据与业务脚本。

```
ui/
  ui.css        设计令牌、字号/字重、材质、控件、全局顶栏与章节目录
  ui-pages.css  逐页修正（选择器以 body[data-page="…"] 开头，保证覆盖旧样式）
  ui.js         统一顶栏、上一页/下一页、十页目录、移动端抽屉
```

页面接入方式（已对十页及两个案例页完成）：

```html
<link rel="stylesheet" href="ui/ui.css">
<link rel="stylesheet" href="ui/ui-pages.css">
...
<script src="ui/ui.js" defer></script>
```

## 设计约定

| 项目 | 取值 |
| --- | --- |
| 底色 | `#08090b`，中性石墨，不再使用藏青 / 紫光渐变 |
| 文本 | `#f5f5f7` / `#a6adb8` / `#868d99`（对比度 18:1 / 8.7:1 / 5.9:1） |
| 强调色 | 系统蓝 `#0a84ff`，语义色仅用于数据状态（绿 / 橙 / 红） |
| 字体 | `-apple-system` → `PingFang SC` / `HarmonyOS Sans SC` / `MiSans` → `Microsoft YaHei UI` |
| 字号 | 11 / 12 / 13 / 15 / 17 / 20 / 24 / 30 / clamp(…)；正文 12.5–15px，行高 1.65–1.8 |
| 字重 | 400 / 500 / 600；中文标题不再使用 800–900 |
| 圆角 | 控件 8–10，卡片 14–18，浮层 20–22，胶囊 999 |
| 材质 | `backdrop-filter: blur(26px) saturate(180%)` + 1px 白色 hairline |
| 动效 | `cubic-bezier(.32,.72,0,1)`，180–300ms；支持 `prefers-reduced-motion` |

## 主要修正

- 统一顶栏：品牌、章节号、上一页/下一页、目录；桌面居中弹窗，移动端底部抽屉。
- 移除了旧的右下角悬浮胶囊导航，以及各页重复的页头（today / fun / choices / 两个案例页）。
- 修复对比度缺陷：全息工作区“最近变化”横幅（浅底浅字）、详情卡标题（`#1c1c1e` 深色字）、标签选中态等。
- 修复移动端：全息三栏改为单列（图 → 详情 → 筛选）、路径页事件卡横向滚动、忽略了什么的 SVG 图可横向查看。
- 报告页的滚动显现动画改为直接可见，避免未滚动时整页空白。
- 统一 8pt 间距、卡片内边距、按钮高度与焦点环；移除 800/900 字重、发光文字、扫描线与大面积紫光。
